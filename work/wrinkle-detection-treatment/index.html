Wrinkle Detection & Treatment

ML Engineer — Computer Vision, 3D Geometry, Training & Cloud Infrastructure (IaC/CI)

The Problem

The platform needed to automate a clinical workflow based on facial images: detect regions of interest, generate a geometrically consistent treatment plan, and produce a final 3D mesh consumable by the application.

The challenge was not just model inference, but coordinating multiple asynchronous stages with medical review between steps, ensuring only clinically approved data feeds training, moving from 2D detections to 3D geometry with safety constraints, and maintaining traceability per patient, environment (dev/prod), and execution.

Cloud Job Pipeline

I designed and implemented three independent jobs deployed as Cloud Run Jobs, coordinated via Firestore and Cloud Storage:

Detection — YOLO inference: wrinkle segmentation, eyebrow detection (rest/raised), and periocular detection.

Treatment — consumes reviewed detection + patient 3D mesh; computes safe geometry, application points, and geodesic overlays.

Mesh Builder — takes the approved plan and generates the final 3D mesh (Blender pipeline) for the application.

The flow includes clinical review pauses: each stage writes its result, a physician approves or corrects, and only then does the next stage proceed. Manually edited cases are kept as improvement signals for future training cycles.

Model Training Cycle

I built and ran the end-to-end ML cycle: data preparation, GPU training, and weight deployment to production.

Internal dashboard (Streamlit) with two pipelines: YOLO (extracts clinically approved data, generates labels, visual train/val review) and Gemini FWS (JSONL examples for fine-tuning on Vertex AI). Tasks: forehead wrinkle segmentation, crow's feet, and eyebrow detection.

I trained three YOLO models on Vertex AI Custom Jobs: wrinkles (YOLO26s-seg, segmentation), crow's feet (YOLO26s, detection), and eyebrows (YOLO26m, detection). Flow: export dataset → publish to GCS → Cloud Build → Vertex Custom Job → val evaluation → deploy to detection job.

I also implemented the Gemini fine-tuning pipeline for the facial zones module (FWS), with a dedicated builder and review dashboard.

3D Validation, IaC & CI/CD

I added structural validation for facial meshes (topological integrity, UVs, degenerate components) to catch invalid assets before they break the treatment pipeline.

GCP infrastructure as code with Terraform (multi-environment dev/prod): Cloud Run Jobs, Artifact Registry, service accounts, Google Cloud Workflows, and IAM. GitHub Actions with Workload Identity Federation for selective per-job build and deploy, with no long-lived JSON keys in the repo.

Impact

Production-ready end-to-end vision + geometry pipeline, with a reproducible training cycle and clinical quality control.

Three trained and versioned YOLO models with traceable artifacts in GCS, Gemini fine-tuning pipeline for facial zones, infrastructure versioned in Terraform, and automated deployments with GitHub Actions.

Reduced risk through mesh validation and medical approval gates between stages.
